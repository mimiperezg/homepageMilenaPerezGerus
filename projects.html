Lake Water Quality Monitoring

NASA DEVELOP

Helped develop and test LakeSense, an automated pipeline that processes Sentinel-2 and Landsat 8/9 imagery to monitor lake water quality in North Dakota.

  • Implemented and evaluated atmospheric correction methods and quality flags
  • Compared satellite-derived outputs with Level-2 products and field measurements
  • Troubleshot Python processing workflows on a remote computing cluster
  • Shared findings with NASA advisors and state partners through maps, time series, a technical report, and a presentation

Python, Sentinel-2, Landsat 8/9, GIS, remote computing (SSH)

Machine Learning for Cloud Detection in Satellite Imagery

Machine Learning, Northeastern University

Compared traditional machine learning models with a convolutional neural network for detecting clouds in Landsat 8 imagery from the 38-Cloud dataset, weighing interpretability against predictive performance.

  • Implemented and evaluated Random Forest, SVM, and CNN models
  • Engineered statistical and spectral features, including NDVI and brightness
  • Tuned hyperparameters and analyzed feature importance to compare interpretability with accuracy

Oct–Dec 2025

Rotation-Equivariant Land Cover Classification

Geometric Deep Learning, Northeastern University

Tested whether building rotational symmetry into a convolutional neural network makes land cover classification on Sentinel-2 imagery (EuroSAT) more robust than data augmentation alone.

  • Reproduced a baseline CNN for satellite image classification
  • Implemented a C4-equivariant CNN using group convolutions
  • Ran equivariance tests, controlled experiments, and ablation studies on rotational augmentation
  • Showed the equivariant model stayed more stable on rotated images it never saw during training

Python, PyTorch, E2CNN, Sentinel-2
